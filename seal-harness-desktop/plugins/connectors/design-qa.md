# 连接器工作台视觉 QA

目标基准：用户提供的 Stratex 连接器页，窗口 1438 × 900。

## 已核对

- 顶栏：返回、连接器路径、RESOURCE、同步状态、刷新、创建连接器、已安装计数。
- 首屏：WORKBENCH RESOURCE、36px 主标题、说明文案、右侧全局搜索与 Ctrl K 提示。
- 目录：精选场景双列卡片、办公类/开发类数量与筛选、已安装快捷导览。
- 管理区：个人计数、批量管理、名称/时间排序、双列连接器卡片、状态与标签。
- 操作：创建/编辑安全表单、启停、重连、工具查看、删除确认、批量启停/删除。
- 自适应：820px 以下切为单列，顶栏和个人区控件允许换行。

## 验证

- Client 契约测试覆盖页面结构、场景筛选、创建对话框、批量模式和返回行为。
- Host 测试覆盖 HTTP/stdio 生命周期、凭据不回传、失败恢复、账号隔离和远程安装。
- `corepack yarn seal-harness:build`、`verify.mjs`、`verify-profile.mjs` 均通过。
- 本轮 Windows 图形会话的桌面合成输出为纯黑，无法据此做可靠像素截图；未将该环境现象冒充为视觉通过。
