# 设置改成主内容全页

取消模态弹窗，点击底部设置进入一级主内容区；保持最左导航，设置内部左分类/右内容，不固定方形或16:9。沿用所有设置菜单的表单、功能和保存行为。

现有电脑操作页不协调的大块底色、内容挤在右侧需要修正；逐项检查通用设置、模型、内置插件、问问决策、Agent预设、图片生成、WeKnora、电脑操作、Token统计、桌面设置及运行时实际登记的其他菜单。

验收：无设置modal遮罩/inert/全页focus trap；设置快捷键与指定分类打开仍能用；离开页面正常；菜单切换/保存/嵌套弹窗不破坏。宽屏与窄窗口不溢出，页面内边距/标题一致，按钮可达。构建、定向及产品完整check、逐菜单GUI验证。保留Univer移除等他人改动，禁止提交/推送。
