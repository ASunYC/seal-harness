# 应用管理与 DBX

首页二级菜单增加“应用”，与专家、技能、连接器、插件并列。首版仅支持 Windows x64/ARM64 的 DBX 便携版，安装桌面程序和独立 MCP，能打开程序并在现有会话连接器中选用 DBX 工具。

## 验收

- 未安装显示“＋ 安装”；安装中禁止重复操作并显示进度；安装后不出现安装加号，显示打开、卸载；卸载完成恢复安装按钮。
- 固定官方 Release 与 SHA-256，校验 ZIP 路径、大小和普通文件；程序安装和 SQLite 状态一致，失败可重试，重启状态可恢复。
- 复用现有产品 SQLite 和 Host-only connector 接口；应用和连接器按当前本机账号隔离。退出账号/卸载停止 MCP，不留下可调用工具。
- DBX 和 MCP 使用同一个独立数据目录；卸载删除本应用管理的二进制并移除关联连接器，保留数据库连接配置；不碰既有系统 DBX。
- 真实官方包下载、MCP handshake/工具发现、打开与卸载，以及按钮完整生命周期实测；产品构建和产品检查通过。数据库远端查询需要用户自行配置真实连接。
