# 统一非首页一级页面留白与标题样式

## Goal

统一自动化、统计、知识库、桌面、ACP、空间、市场的内容边距及主副标题，并以真实页面测量验证

## Requirements

- 仅统一自动化任务、Token统计、知识库、远程桌面、ACP、空间和插件市场；首页、决策及其资源页不改。
- 桌面内容内边距统一32px，窄窗口统一20px；页面保留原滚动与操作，左右采用对称滚动槽避免滚动条挤偏内容。
- 主标题统一24px/32px、600字重；已有副标题统一14px/22px、400字重，标题间距8px，字体与颜色一致。
- 在产品navigation统一样式层收敛，不复制业务页面、不修改只读上游，不为缺少副标题的上游页面伪造介绍。
- 保留所有既有未提交改动；不提交、推送或发布。改后重建并重启，实际逐页测量宽窄窗口。

## Acceptance Criteria

- [x] 七页左右内容留白与顶部起点一致，宽窄窗口均可核对。
- [x] 七页主标题计算样式完全一致，存在的副标题计算样式完全一致。
- [x] 原有操作/滚动/导航及首页决策隔离保持，构建和对应检查通过。

## Change Boundary

根因是各插件自带不同padding/font/header规则，自动化页面还有居中960px上限。只在navigation新增统一page-styles.js，并由现有样式生命周期装配；使用产品页面类和上游task-manager-page根范围定位，不修改上游任务状态、组件或按钮。新样式通过root作用域优先级覆盖后加载的模块规则。真实浏览器测量与夹具验证，不增加与CSS逐字镜像的测试。
