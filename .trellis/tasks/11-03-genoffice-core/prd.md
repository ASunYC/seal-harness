# Apache Office core

Integrate pinned Apache-only GenOffice document engines into brand/account-isolated local Office editing. Actual DOCX/XLSX/PPTX create, import, inspect, edit and export; preserve imported originals as immutable revisions. No AI provider calls, keys, telemetry, ee or native sidecar. Clearly state structured editing versus full upstream Electron GUI, native recalculation and pixel rendering. Preserve prior removal and all unrelated modifications.
