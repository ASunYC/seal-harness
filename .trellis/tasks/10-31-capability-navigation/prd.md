# 整合能力导航并调整一级菜单

## Goal

将技能、连接器、插件和应用归入一级“能力”，整理桌面导航，并将 Token 统计移至设置面板。

## Requirements

- 一级顺序：首页、能力、知识库、自动化任务、问问决策；其余现有入口保留在后面。
- 能力内提供插件、技能、连接器、应用四个可切换入口，沿用各自原有页面与数据。
- 首页资源列表不再重复显示这四项。插件市场仍可从插件能力访问。
- Token 统计在设置内可用，一级栏不再显示。
- 现有会话、工作区、设置入口和用户侧栏收起偏好保持可用。

## Acceptance Criteria

- [x] 点击“能力”可以在四个页面之间切换，插件管理页面及插件市场仍可访问。
- [x] 一级导航顺序符合要求，条件加载的问问决策位于自动化任务下方。
- [x] 设置里可查看 Token 统计并导出，一级导航不再出现 Token 统计。
- [x] 导航与统计相关测试、桌面构建和界面检查通过。
