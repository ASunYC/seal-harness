# 移除项目插件

## 目标

移除 Seal Harness 侧栏的“项目”入口及其整个产品插件，不影响其他产品插件和 DSH 原生工作区、会话。

## 范围

- 删除 `seal-harness-desktop/plugins/projects/` 的 Host、Client、样式、包声明、文档和测试。
- 从产品插件清单、Cordis Profile、构建、装配、打包与检查中移除项目插件；清理旧装配包。
- 更新当前产品文案和工程契约，不再宣称提供本地项目管理。
- 保留现有工作目录、DSH 会话及用户 Home 的 SQLite 数据。已有 `projects` 表作为历史数据保留，不主动清除用户记录。

## 验收

- [x] 应用侧栏和产品 Profile 没有项目入口或项目插件。
- [x] 产品装配与包目录不存在旧 `@seal-harness/projects`。
- [x] 其他插件与原生会话可加载，产品构建和完整检查通过。
- [x] 文案、规格和验证记录反映当前状态；不删除用户目录或数据库记录。
