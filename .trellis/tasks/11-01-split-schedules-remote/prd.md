# 自动化任务与远程主机左右布局

## Goal

原生自动化任务固定左侧列表；远程主机左侧选择主机、右侧显示详情与操作

## Requirements

- 一级自动化任务继续使用 DSH 原生 `schedules` 页面与数据；左栏固定展示原生筛选、搜索和任务列表，右栏展示选中任务的原生详情。
- 远程主机左栏展示可搜索、可筛选的主机列表，右栏展示所选主机的现有详情、客户端状态与连接、检查、编辑、删除操作。
- 空列表、筛选无结果、加载失败和删除当前项时，左右栏保持稳定且可继续操作。窄窗口可用，不能丢失任务或主机操作。
- 保留已有账号隔离、RPC、原生客户端启动和任务执行语义，不合并两套定时任务数据。

## Acceptance Criteria

- [x] 原生自动化任务无选择和有选择时，列表均位于左侧，详情或引导位于右侧。
- [x] 多主机可在左侧切换，右侧内容随选择更新；筛选、删除与空态不产生陈旧详情。
- [x] 相关组件测试、产品构建及检查通过，用户已有未提交改动保留。

## Notes

导航和应用样式中已有其他未提交修改；本任务只改必要路径。
