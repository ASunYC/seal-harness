# 远程主机

替换本机桌面插件：支持按本地账号保存多台服务器的 SSH/RDP/VNC 连接配置，增删改查、搜索、连接前检查、打开真实协议客户端。完全删除本机截图及键鼠输入能力。一级菜单位置及统一页面风格保持。

采用成熟原生客户端窗口，不自写协议栈；SSH OpenSSH终端，RDP Windows mstsc/Linux FreeRDP，VNC TigerVNC。客户端缺失清楚提示安装或选择绝对路径。密码/私钥口令与主机/证书验证在客户端完成，不存储或返回密码，不关闭协议安全校验。

验收：多账号隔离与重启持久化；严格主机端口参数，不接受shell命令；客户端探测/网络超时/取消/缺失错误；进程启动只称已启动，不称登录成功。协议夹具、注入边界、迁移、构建/UI/Profile检查通过。用户暂无远端设备，真实SSH登录/RDP/VNC桌面及macOS/Linux实测列为交接验证，不伪称已测。保留其他改动，禁止提交/推送。
