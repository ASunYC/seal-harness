# 独立组织架构插件

## Goal

将 Octop Enterprise 的本机组织目录核心能力移植到 Seal Harness 的 Cordis Host 服务端，作为与专家、技能类似的独立产品插件装配，并提供可操作的目录界面。

## Requirements

- Host 持久化公司名称、层级部门、人员、岗位；支持新增、修改、停用或删除、部门移动、人员归属与按名称/部门/岗位搜索。
- 校验部门循环、跨账号引用、无效输入与删除非空部门；组织资料按当前本地账号隔离，未登录不得读写。
- 客户端插件通过现有导航服务独立注册入口，展示部门树、人数、人员详情和管理操作。参考 Octop 截图的组织目录，不伪造通信状态。
- 数据留在 Seal 本机数据库；本阶段人员是目录资料，不自动成为可登录账号。消息、群聊、在线状态及跨设备同步另立任务。
- 优先复用 DSH 插件、Connection RPC、导航和 SQLite 服务，不改只读上游与 Octop 源码。
- 保留当前其他任务的未提交改动；不提交、推送或发布。

## Acceptance Criteria

- [x] 独立组织插件在产品 Host/Client 构建和 Profile 中装配，导航可进入页面。
- [x] 旧数据库升级后原用户与已有数据保留，重启后组织数据可读。
- [x] 部门层级、循环防护、人员归属、账号隔离与未登录拒绝有回归测试。
- [x] 页面可完成部门和人员的创建、编辑、查找与删除/停用，并显示明确错误。
- [x] 受影响产品检查通过，报告未实测的图形安装和跨平台事项。

## Boundaries

本轮不实现消息、群聊、在线状态或跨设备同步；目录人员不是本地登录账号。
