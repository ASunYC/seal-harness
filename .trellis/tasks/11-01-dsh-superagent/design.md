# 设计

官方原型会修改进程级 PATH 和 git 配置，并建议独立 Web Profile。Seal 主进程继续使用现有 DSH `0.2.1-rc.2`；Linux 容器内使用官方部署文档的 DSH `0.2.1-rc.3` 与固定提交的 Superagent，避免污染用户会话。容器仅将面板映射到 Windows 的 `127.0.0.1:3082`，DSH 数据和工作目录用 Docker 卷持久化。

Seal 产品插件只提供只读状态和打开独立面板的入口。状态通过固定本机地址的管理 API 获取，避免客户端跨源限制。插件不持有 GitHub 或模型密钥，不替用户扩大授权。

服务先启动到待配置状态；专用 GitHub 账号、模型供应商和允许列表配置由用户在独立面板与 CLI 中完成。默认 Policy 使用 observe，不自动执行未经核实的请求。
