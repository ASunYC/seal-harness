# 重构专家页并通过会话创建专家

## Goal

系统/个人专家页签，移除安装和手工编辑流程，模型工具保存个人专家

## Requirements

- 专家页顶部移除“已同步”文案、绿点和刷新按钮；“导入专家包”改为“导入专家”。
- 移除“我的专家”按钮、悬浮面板及其专属状态和交互。
- 移除“已安装”区及安装式文案，不删除已保存的专家数据。
- 移除“本地专家”标题和公开/授权目录，页面仅保留“系统”“个人”两个页签。系统页暂为空态，为未来产品内置专家卡片预留；当前用户创建或导入的专家显示在个人页。
- 删除手工创建专家的整页表单。点击“创建专家”新建并打开原生会话，将可编辑的专家创建模板放入输入框，不自动发送。
- 用户修改模板并发送后，大模型通过产品注册的工具创建专家；工具调用现有专家保存逻辑，以当前本机账号的 SQLite 为持久来源，同时按现有机制物化必要专家文件。成功后模型明确告知创建完成；再次进入专家个人页可看到新卡片。
- 不预填假的系统专家，也不把模型生成的纯文本误报成已保存专家。

## Acceptance Criteria

- [x] 专家页无同步、我的专家、已安装、本地专家、公开/被授权及手工创建页；导入按钮正确命名。
- [x] 系统/个人两个页签可切换；个人显示当前账号专家，系统无内置数据时明确空态。
- [x] 创建按钮打开原生会话，输入框有可编辑模板且不自动发送。
- [x] 模型可调用创建工具，按当前账号保存专家；成功回复可确认名称，重新打开个人页可读取。
- [x] 错误、缺少模型或不存在的技能/连接器不会被误报为创建成功；定向测试、产品构建及真实窗口验证通过。
