# 插件化接入 Token统计、知识库、远程桌面与ACP

## Goal

将截图中的 Token 统计、知识库、远程桌面、ACP 四块能力作为独立产品插件接入 Seal Harness；每块由子智能体负责实现，主智能体负责共享接入和综合验证。用户授权普通技术取舍按推荐方案推进，无需反复确认，不提交或推送。

## Requirements

- R1：一级导航顺序：首页、问问决策、自动化任务、Token 统计、知识库、远程桌面、ACP、空间、插件市场。四块页面均采用非首页全宽布局。
- R2：Token 统计读取真实运行用量，支持时间范围、汇总/每日/专家/模型维度与导出；处理重复事件、重启和账号归属，不伪造费用或未记录的历史。
- R3：知识库复用现有 WeKnora 连接及检索工具，提供库/文档管理、导入及状态、检索和模型设置入口，明确未连接/权限不足/模型未配置；优先服务现有运行链路，不另建重复向量引擎。
- R4：远程桌面插件提供明确的设备就绪检查、连接/断开、真实屏幕显示与可支持的输入控制，优先复用 DSH 公开服务。输入须绑定当前账号、当前连接与显式连接动作；不自动开放公网或未经授权的第三方设备。
- R5：ACP 插件提供预设和自定义 Runner 的配置、检查、启停/连接和真实 ACP 执行接入，复用现有 DSH ACP 服务/子智能体协议，不用普通 shell 冒充 ACP。凭据沿 Host 管理，未安装或未授权明确显示。
- R6：每块包含真实 Host/Client、生命周期清理、账号边界、错误状态和有意义的测试，不用截图卡片/假零数据冒充完整能力。外部依赖未就绪时说明所缺条件。
- R7：保持上游只读、产品自有目录、Node/Yarn及单 SQLite；保留当前未提交的反馈移除和导航改动。

## Acceptance Criteria

- [x] 四个插件真实装配并按 R1 注册一级入口，非首页无宽侧栏，返回首页偏好保留。
- [x] Token 真实事件汇总/筛选/导出、重复/重启/账号边界测试通过。
- [x] 知识库管理与检索闭环通过可控服务回归，并记录真实服务端的联通/依赖状态。
- [x] 远程桌面真实截图/支持的控制路径、连接隔离、断开及失败清理有验证。
- [x] ACP 通过受控协议 Runner 实测握手/执行/取消/错误，并检查预设可用性。
- [x] 共享数据库迁移、产品 build/check、真实 Electron Profile 和 Windows 页面综合测试通过；未验证平台和外部服务如实记录。
- [x] 未执行 Git 提交、推送、发布或修改上游子模块。

## Implementation Boundary

四块分属 `plugins/token-stats`、`plugins/knowledge`（可增量修改现有 `weknora`）、`plugins/remote-desktop`、`plugins/acp`。共享 navigation、build/profile、local-data 迁移、总规范与集成验证只由主智能体修改。参考 Octop 使用语义和真实协议，保留许可，不复制其整套服务端或品牌。手机与跨主机连接仅在已有协议/配对能力支持时启用，不提供假就绪入口。

交付及实测范围见 [validation.md](validation.md)。
