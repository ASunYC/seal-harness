# 内置 Blender MCP 连接器

## 目标

在 Seal Harness 的「能力 → 连接器 → 系统」中提供 MCP for Blender 安装入口，复用现有账号、会话选择和 MCP 工具生命周期。

## 要求

- 使用 `ahujasid/mcp-for-blender` 官方 Python 包的固定版本，不复制其服务或 Blender 插件源码。
- 安装入口先检查 `uvx`，通过官方命令安装 Blender 用户插件，再保存本账号的本地 MCP 配置；失败不得显示已安装。
- 保存后的连接器默认关闭，用户在 Blender 中启用插件和启动 MCP Server 后由现有连接器管理页启用。
- 展示版本、来源、MIT 许可和 Blender 及 uv 的先决条件；不修改其他 MCP 客户端配置。
- 目录卡片与已安装连接器共用项目自带、可见的 Blender MCP 图标，并保留资产来源和许可。
- 保留其他用户当前未提交的工作区修改。

## 验收

- [x] 系统目录显示 Blender 条目，安装配置使用固定包版本和绝对 `uvx` 路径。
- [x] 无 `uvx`、插件安装失败、账号切换时不保存假安装状态。
- [x] 目录、账号和 MCP 生命周期回归通过，产品构建和检查通过。
- [x] 内置图标使用上游原始 PNG，目录卡片和已安装项均携带同一图标。
- [ ] 在有 Blender 的机器上完成真实插件启动及工具调用验证；本机没有检测到 Blender，未运行。
