# 自动化任务直接创建

用户要求点击“新建自动化任务”直接填写并保存定时计划，不再新建会话。已有产品scheduled-tasks具备账号隔离保存、once/daily/weekly/interval时间规则、真实调度与执行记录；当前导航误指向native schedules会话提醒。

范围：navigation一级入口与选中状态、scheduled-tasks客户端及表单/左右布局、对应测试与契约。默认进入产品计划页，原native会话任务从“会话提醒”按钮仍可查看，数据不迁移。仅执行/打开结果会话时进入会话。

验收：两个新建入口都在原页打开表单，保存显示任务和下次运行时间，取消不保存、不创建会话；四种频率有效、错误可修正；真实持久化和调度测试，账号隔离、暂停/启用、删除保留；原会话提醒仍可访问。浅深主题宽窄布局。先不提交或推送。
