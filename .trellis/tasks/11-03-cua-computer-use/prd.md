# 内置电脑操作：本机与虚拟机

用户已要求两种模式全部接入。默认本机、强制后台操作：不得抢鼠标/键盘焦点；不支持后台的动作必须拒绝，不能回退前台。虚拟机模式通过SSH stdio MCP连接已安装Cua Driver的来宾桌面；支持多目标配置，不创建/安装Hypervisor。

保留Seal现有模型和会话。内置computer-use产品插件，设置/会话能力按钮切换目标和启停，观察与图像按原生工具结果回传。目标/运行状态按账号及会话隔离，停止/退出/卸载撤销所属连接。默认禁用全局桌面坐标、前台操作、终止任意进程和浏览器接管。

固定Cua Driver 0.38.0发布资产（上游标记prerelease，必须记录），随包包含校验的基础Driver及许可，不含AGPL perception。不得运行上游安装器或给其他coding agents安装技能，不自动更新。VM已有SSH密钥/Agent认证，严格known_hosts；Windows guest必须用交互桌面daemon的named pipe，不误连SSH Session0；Linux需图形会话环境，macOS保留app授权。

测试：真实MCP握手/发现、图片结果、后台UI操作和用户鼠标/前台窗口不变；VM使用SSH/协议夹具并明确暂无真实VM。持久化/跨账号/跨会话、拒绝前台动作、取消/停止、产品build/check和GUI。保留其他窗口的Univer移除工作。不提交/推送。
