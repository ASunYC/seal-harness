# 修复汇总布局并统一选择器与页面操作

## Goal

修复Token汇总压缩、技能连接器系统个人口径、知识库图标操作和删除桌面手机占位

## Requirements

- Token 汇总表不再被纵向 flex 压缩，外层页面负责纵向滚动，表格保留横向滚动。
- 技能与连接器会话选择器统一“系统 / 个人”，分类规则复用管理页；目录/市场项目为系统，个人创建/导入和工作区技能为个人，内置bundled/runtime技能为系统。
- 知识库刷新、设置改为等尺寸图标按钮，保留aria-label和title悬浮提示，行为及新建知识库按钮不变。
- 删除产品远程桌面里的手机入口、状态字段和相关占位文案；不修改上游原生设备能力。
- 保留其他窗口及此前未提交改动，不提交或推送；构建、定向测试及真实页面核对。

## Acceptance Criteria

- [x] 已有用量下汇总标题与表格完整显示，窄窗口表格可横向滚动。
- [x] 两个选择器均出现系统/个人分组，来源匹配且搜索、插入技能、连接器切换保持正确。
- [x] 知识库两个图标按钮可访问、提示正确且原操作正常。
- [x] 产品桌面UI/API不再提供手机占位，桌面连接能力不变。
- [x] 相应回归、产品构建/检查和Windows实际UI验证通过。

## Change Boundary

修改Token样式、capability-shared目录规则及引用它的管理页/会话选择器、knowledge工具栏、remote-desktop自有UI/API/对应测试和当前规范。不改账号/凭据、数据存储、只读子模块或其他协作者的标题栏工作。

会话技能DTO省略source，因此增加产品Host只读来源查询，复用公开sessionQuery/agentPresets/skills服务，不修改上游。
