# 设计与边界

来源工程没有 Git 历史，因此先按路径映射和品牌文本规范化比较，不直接覆盖整个仓库。`geovis-zhizuo-desktop/` 映射至 `seal-harness-desktop/`，`@geovis/zhizuo-*` 映射至 `@seal-harness/*`；运行时服务名仍遵循 `sealHarness*`，系统提示词变量仅用合法下划线。原产品图标、`product.json`、默认服务配置、主 README、CI 与当前迁移验证记录保持 Seal Harness 所有。

增量主要在产品插件内：资源导航和同步提示、连接器交互与运行时、会话技能选择与删除流程，以及相关测试。新源文件按语义迁入；已有文件用差异补丁整合，不复制来源的旧品牌或本机截图路径。

来源新增的 Yarn patch 改动了上游默认工作目录。只有确认该行为是本产品需求且不破坏固定运行时验证时，才将其适配为 `seal-harness` 并更新根 resolution/lock；否则记录为未采纳差异。

验证先跑受影响测试与产品构建/检查，再跑根布局、类型、LFS 与 Git 检查。产品源码与上游共享包分开处理。图形视觉检查须在实际 Electron 环境另记。
