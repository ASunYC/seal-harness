# 两级导航与资源界面重构

## 目标

参考用户截图中 Codex 的左侧窄栏与相邻侧栏的层级，让 Seal Harness 有清晰的一级导航；专家、技能、连接器等产品资源作为二级菜单出现，并重新统一产品界面风格。

## 已确认的意图

- 保留当前原生对话入口；第一级新增“首页”“空间”“定时任务”。
- “首页”的第二级菜单包含专家、技能、连接器，三者不再作为平铺的第一级入口；功能与本地数据保持。
- Codex 是导航层次、密度和视觉感受的参考，不要求复制品牌或整套功能。
- DSH 原生会话、工作区、输入框与模型链路需要保留；产品专属代码优先放 `seal-harness-desktop/`，避免复制上游 Desktop UI。

## 待收敛的产品决策

- “空间”首版接入现有 DSH 工作区；“定时任务”首版提供可见入口和明确空态，不创建后台调度或假任务数据。
- 原生插件管理入口保持其独立入口，设置/账号保持现有底部位置；不重写第三方插件管理。
- 本轮统一导航壳、资源页页头与背景间距；专家/技能/连接器的内部业务操作和数据模型保持现有行为。
- 暂按一级导航常驻独立窄栏实现；用户如选择沿用现有侧栏，再调整布局方式。

## 初步验收

- [x] 一级导航保留原生对话，并可切换首页、空间、定时任务，当前区域有明确选中状态。
- [x] Windows 兼容模式主窗口最左侧有常驻窄栏，旁侧栏内容随一级入口切换；标题栏与会话区域未被覆盖。
- [x] “首页”二级菜单显示专家、技能、连接器；入口与内容页切换可用。
- [x] “空间”展示并打开现有工作区；“定时任务”明确说明当前没有任务能力，不展示假数据。
- [x] 原生会话及输入框状态在切换后保持正常，产品插件卸载/重载无残留菜单。
- [x] Windows 实测深浅色与 760px 窄窗口；按钮可聚焦并有无障碍标签。
- [x] 产品构建、Profile、定向 UI 测试通过；真实 Windows 兼容模式截图对照用户参考。macOS/Linux 与其他模式另行实测。
