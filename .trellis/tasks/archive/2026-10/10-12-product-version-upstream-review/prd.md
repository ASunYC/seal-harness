# Seal Harness 产品版本与 DSH Desktop 更新评估

## 目标

让标题栏所示版本及将来的产品安装包版本跟随 `seal-harness-desktop/package.json`，不再显示承载它的 DSH Desktop Beta 版本；抓取官方 DSH Desktop 最新分支，对照当前基线，评估近期更新哪些适合独立移植。

## 边界

- 保持 Seal Harness 当前已定的 `0.1.0` 版本号；不擅自升级主/次版本。
- 产品构建从产品包 manifest 注入版本，开发运行与打包使用同一来源；默认 DSH Desktop Stable/Beta 构建保持原版本语义。
- 不直接合并整个上游分支，不改变只读 `deepseek-harness/` pin，也不接受 DSH 社区更新渠道。
- 上游分析以 `v2.0.14-beta.1` 对 `v2.0.17-beta.2` 和最新 `master` 的提交、发布记录及相关源码为证据，区分可独立移植与需要新版内核的内容。

## 验收

- [x] Seal Harness 构建后的原生标题栏版本使用 `0.1.0`，打包配置与解包应用清单也使用 `0.1.0`；以后改产品包版本后自动同步。完整打包结束与安装另行验证。
- [x] 默认 DSH Desktop 构建仍显示它自己的 package 版本。
- [x] 产品构建、相关测试、类型/双变体检查通过，并记录未验证的平台。
- [x] 已抓取最新上游引用，给出有来源的更新清单、适配优先级和风险；不会悄悄合并整树。
