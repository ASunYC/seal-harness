# 首页二级插件管理

用户纠正：当前对话不属于一级菜单；插件管理与专家、技能、连接器同属首页二级菜单。

## 范围

- 移除一级窄栏“对话”按钮，保留原生新会话、工作区和返回对话的现有操作。
- 首页二级菜单与概览增加“插件”；点击打开现有 DSH 插件管理主面板，首页一级图标保持选中，旁侧二级菜单保持可切换。
- 原生侧栏中旧的独立“插件”行不再显示；不禁用插件管理服务或修改只读子模块。
- 更新测试与当前产品文档；用户数据和插件安装状态不变。

## 验收

- [x] 一级窄栏只有首页、空间、定时任务，没有对话按钮。
- [x] 首页二级菜单包括专家、技能、连接器、插件，插件管理功能可进入且可切回其他二级页面。
- [x] 原生侧栏没有可见的独立插件入口；原生新会话入口保留。
- [x] 构建、产品检查及 Windows 窗口验证通过。
