# 登录更新设计

Seal 自有 identity 插件承载 UI 与本地认证，不修改上游 DSH。视觉参照 Octop 的桌面卡片排版、深色调及交互，保留 Seal 图标和名称。滑块只限制客户端表单提交；密码仍由 Host 的 scrypt 校验。

记住登录使用随机 256-bit 凭证。渲染器只在持久 Electron 分区的 localStorage 保存不含用户信息的凭证；SQLite 只保存 SHA-256 摘要、所属账号和到期时间（30 天），不保存明文密码。启动时通过现有 identity RPC `resume` 核对凭证和账号状态，成功后换发凭证并建立新的进程内会话。退出或改密撤销；不勾选的登录撤销该账号旧凭证。无凭证/无效凭证回到普通登录，旧数据库升级新增表并保持原有用户数据。

localStorage 与产品数据库都属于本地用户状态，产品默认数据目录及 DSH_HOME 覆盖不变。恢复失败不能阻断密码登录。新存储键和数据库表独立于既有配置，旧安装没有键时继续按现状运行。
