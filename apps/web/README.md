# @seal-harness/web

![Seal Harness mascot](public/assets/seal-harness-mascot.png)

Local-first Web UI and streaming HTTP host for Seal Harness.

```sh
seal-harness web
```

The server binds to `127.0.0.1:3080` by default. API keys entered in the UI remain
in process memory and are not written to Session files.
