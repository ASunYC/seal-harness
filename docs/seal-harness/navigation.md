# 两级桌面导航

2026-10-01 用户参考 Codex 桌面应用的左侧窄栏，要求 Seal Harness 将主要区域与资源入口分层。用户提供的 Codex checkout 不含截图中的桌面渲染源码；实现复用 DSH Desktop 的公开 slot、布局与工作区服务，没有复制 Codex UI 代码。

## 一级与二级

最左侧窄栏提供“首页”“空间”“定时任务”，不单设对话按钮。首页二级菜单显示“专家”“技能”“连接器”“插件”等功能入口，不设概览页、资源卡片或重复的会话菜单。顶部“新会话”按钮进入原生 DSH 对话及输入框；点击一级“首页”也可返回当前对话。选择资源时顶级首页入口保持激活。专家、技能、连接器的 Host/RPC、SQLite 数据与 React 页面保持独立，Client 通过导航服务注册二级入口，卸载时自动撤销。

会话输入框里的“打开技能页”“管理连接器”“智能助手”快捷入口会切到首页并选中对应二级页面，不再指向已撤销的旧平铺面板。

插件管理复用 DSH 原有主面板，在首页二级菜单打开；旧侧栏独立行隐藏。空间直接展示、添加和打开 DSH 工作区，原生侧栏仍显示会话列表。定时任务目前只有入口与空态，界面明确说明当前无法创建或执行任务；不创建假任务，也没有调度、执行或通知服务。设置与账号入口保留在侧栏底部。

## 扩展边界

导航插件 `@seal-harness/navigation` 用 `shell.overlay` 绘制一级窄栏，并在原生聊天、首页资源、插件管理及定时任务模式覆盖 `sidebar.workspaces`；切到空间时释放覆盖并显示 DSH 原生工作区列表。产品样式只调整 Desktop frame 的留白和侧栏拖拽线，不修改只读子模块或上游 Desktop 源码。窄窗口中 DSH 折叠侧栏时，资源页及插件页的切换改到主区域顶部。

## 验证

Windows 兼容模式的真实 Electron 窗口已验证对话 ↔ 首页 ↔ 空间 ↔ 定时任务切换、专家子页、深浅色和 760px 窄视口。另有导航状态、资源插件卸载与产品 Profile 测试。macOS、Linux 原生窗口、安装包以及将来定时任务的执行能力尚未验收。
