# Seal Harness v0.2.1

海豹品牌视觉版本。

## 新增

- 使用圆润守护海豹作为正式品牌 IP；
- WebUI 侧栏、欢迎页和浏览器 favicon 使用新海豹图；
- GitHub README 展示新品牌图；
- 自包含发行包携带品牌原图；
- Windows 双击入口与原 CLI 使用方式保持不变。

## Windows

下载并解压 `seal-harness-windows-x64.zip`，双击：

```text
Start Seal Harness.cmd
```

或在终端执行：

```powershell
.\seal-harness.cmd web
```

## 安全提示

WebUI 默认仅监听 `127.0.0.1`。当前版本没有用户认证，不要直接暴露到公网。
